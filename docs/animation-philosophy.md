# Micro-interactions

These make the website feel expensive.

Examples

- Button ripple (very subtle)
- Arrow slides 4px on hover
- Image zooms 3%
- Card lifts 6px
- Navbar shrinks on scroll
- Mega menu fades in
- Active nav underline animates
- Gallery thumbnails highlight smoothly
- Form success animates elegantly

These are tiny details, but together they create a premium experience.

# 🎯 One thing I'd add to make this truly premium

I want us to define a **design token system** from the very beginning.

Instead of hardcoding values throughout the project, we'll have a single source of truth for:

```
Colors
Typography
Spacing
Border Radius
Shadows
Animation Durations
Animation Easings
Z-Index
Breakpoints
```

For example, instead of thinking:

> "This card needs `rounded-2xl` and `bg-[#F8F5F0]`."
> 

We'll think:

> "This card uses the `surface` color and the `card` radius."
> 

That makes the entire design system consistent, easier to maintain, and much simpler to evolve if the client ever decides to refresh the brand.

## My suggestion for one small refinement

The only thing I'd adjust from the earlier plan is the **accent color**.

Instead of using gold everywhere, I'd treat **Antique Gold as a highlight, not a theme**.

Use it sparingly:

- Active navigation
- Small divider lines
- Section labels
- Icons in feature cards
- Button hover states
- Tiny decorative elements

The dominant impression should be **premium photography, elegant typography, generous spacing, and excellent layout**—not the color gold itself.

When people remember the site, I want them to remember the craftsmanship and the experience, not "the website with lots of gold." I think that restraint is what will make the design feel genuinely high-end.
