# 🚀 Development Roadmap

I divide the project into **10 phases**.

Each phase should leave the project in a working state.

---

# Phase 1 — Project Foundation 🏗️

**Goal:** Create the project's backbone.

### Tasks

- Initialize Next.js 16
- Configure TypeScript
- Configure Tailwind CSS v4
- Install shadcn/ui
- Install Framer Motion
- Install Lenis
- Install React Hook Form
- Install Zod
- Install MDX support
- Configure ESLint & Prettier
- Configure path aliases
- Configure fonts
- Create folder structure
- Configure design tokens
- Configure metadata
- Configure sitemap & robots
- Configure image optimization

### Result

A clean production-ready foundation.

---

# Phase 2 — Content Engine 📚

**Goal:** Make the website content-driven.

### Tasks

- MDX loader
- Content parser
- Frontmatter parser
- Category parser
- Product parser
- Machine parser
- Gallery parser
- Related product logic
- Slug generator
- Breadcrumb generator
- SEO metadata generator

### Result

The website understands all content before any UI exists.
